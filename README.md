# Arbitrage & Order Book Scanner Engine

Высоконагруженный асинхронный сканер арбитражных возможностей с защитой от сбоев сеть/OrderBook десинхронизаций.

## Архитектура и особенности
- **Точность:** Вся математическая логика использует `Decimal`.
- **Защита OrderBook:** Детекция разрывов последовательности (`sequence_id`) с авто-запросом Snapshot.
- **Устойчивость:** Circuit Breaker на REST/WS коннекторах и reconnect с экспоненциальным jitter-таймаутом.
- **Производительность:** Ограниченные очереди (`bounded queues`) с обработкой Backpressure.
- **Мониторинг:** Встроенный FastAPI сервер с Prometheus метриками и HealthCheck эндпоинтом.
